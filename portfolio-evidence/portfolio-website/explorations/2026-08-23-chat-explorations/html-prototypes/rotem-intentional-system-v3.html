Selected work · Family Finance

Money data existed. Maintaining it was the work.

The product begins with evidence a household already generates — SMS, notifications and receipts — instead of requiring another manual source of truth.

Real product evidence

Capture what already happens.

Decision

Evidence before certainty.

Ambiguous financial evidence should survive long enough to be understood. That led to persistent queues, duplicate prevention and explicit review rather than silently merging uncertain data.

Turning point

THE SYNC
FAILED.

This is the page's only oversized typographic event because it marks a genuine change in the story: a failed network boundary exposed whether the system's reliability decisions actually held.

Detected → Persisted → Sync error → Still queued
What mattered next

The failure wasn't the most important result.

The evidence remained safely queued. Technically, the system behaved as intended. But that created a new product question: if safety is invisible, does the person using the system know their data is safe?

The evidence didn't disappear.
