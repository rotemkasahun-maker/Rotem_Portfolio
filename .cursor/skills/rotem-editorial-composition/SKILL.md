# ROTEM Editorial Composition

## Purpose
Use for page composition, section rhythm, hierarchy, evidence placement, text measure, whitespace, and recruiter-facing scanability.

## Core principle
Solve composition with proportion, alignment, spacing, silhouette, and evidence relationships before adding visual UI devices.

## Priorities
1. Narrative hierarchy
2. Section silhouette
3. Text measure and line breaks
4. Evidence-to-copy relationship
5. Negative-space rhythm
6. Alignment and asymmetry
7. Responsive integrity
8. Decorative treatment last

## ROTEM bias
Prefer:
- editorial rather than product-marketing composition
- asymmetry with deliberate anchors
- varying section silhouettes
- restrained rules and metadata
- evidence as a compositional object
- narrow text measures for strong statements
- generous but purposeful whitespace

Avoid:
- uniform card grids
- repeating two-column templates for every section
- centering by default
- equal padding everywhere
- generic feature-section patterns
- adding copy to fill empty space
- decorative components to make a weak composition feel designed

## Workflow
1. Inspect the current render.
2. Map major anchors: title, statement, body copy, evidence, metadata, navigation.
3. Identify repetitive geometry.
4. Check whether whitespace is intentional or accidental.
5. Check text width and line breaks.
6. Check whether evidence has enough visual authority.
7. Propose the smallest compositional intervention.
8. Preserve locked copy.
9. Test desktop and mobile before declaring success.

## Questions to ask silently
- Does each section have a distinct silhouette without becoming a different template?
- Is the strongest object in the viewport the intended one?
- Are text blocks too close, too wide, or too similar in scale?
- Is the page reading as a document, magazine, portfolio, or SaaS page?
- Does evidence feel embedded in the argument or pasted beside it?
- Is asymmetry intentional or just misalignment?

## Hard constraints
Do not:
- rewrite copy unless explicitly requested
- add sections to improve rhythm
- add cards, pills, or icons as a default fix
- use motion to hide weak composition
- change unrelated routes
