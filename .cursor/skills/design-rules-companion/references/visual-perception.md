# Visual Perception

Use this reference when the interface has unclear focal points, uneven balance, or confusing emphasis.

## Core heuristics

- Visual weight comes from more than size. Contrast, saturation, isolation, position, and shape all change what users notice first.
- Users scan before they read, so composition determines comprehension speed.
- Elements that are isolated or strongly contrasted can overpower content that is nominally more important.

## Practical application

- Reduce the number of competing focal points in the initial viewport.
- Use contrast and isolation selectively for truly important content.
- Audit the first screen in grayscale to see whether the intended reading order still holds.
- Remove decorative emphasis from secondary elements before increasing emphasis on primary ones.

## Common failure modes

- A decorative badge or panel steals attention from the main call to action.
- Several components all try to be the hero.
- Strong accents appear on labels, dividers, and metadata, flattening hierarchy.

## When the heuristic bends

- Editorial and expressive layouts may intentionally create tension or multiple entry points.
- Visual drama can be useful as long as the primary action or narrative still resolves quickly.
