# UX Laws

Use this reference when a flow feels cognitively heavy, overpacked, or hard to navigate.

## Core heuristics

- Working memory is limited, so structure matters more than raw item count.
- Decision cost increases when choices are numerous, similarly weighted, or poorly grouped.
- Proximity and grouping shape how users interpret interface structure before they read deeply.
- Recognition is usually faster than recall, so visible cues beat hidden conventions.

## Practical application

- Chunk related options into small groups with clear labels.
- Reduce parallel choices at the point of decision.
- Expose defaults and recommendations to lower decision friction.
- Use progressive disclosure when advanced options are important but not always needed.

## Common failure modes

- A settings page presents every option with equal visual weight.
- The user must remember previous input because the interface does not keep context visible.
- Dense menus make scanning slower because related items are not grouped.
- Advanced options compete with the main path too early.

## When the heuristic bends

- Expert tools can show more information when the audience expects density and repetition.
- Some exploratory products intentionally expose many paths, but they still need grouping and orientation cues.
