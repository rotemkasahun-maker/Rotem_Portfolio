# Typography

Use this reference when the interface is hard to scan, feels visually flat, or has inconsistent text rhythm.

## Core heuristics

- Larger text usually needs tighter line height; smaller text usually needs more breathing room.
- Body copy works best with a comfortable reading range rather than the same line height used for headings.
- Type scales should feel systematic. Repeated one-off sizes weaken hierarchy.
- Pair display and body typography intentionally. Distinction helps hierarchy, but the pair still needs shared tone.

## Practical application

- Tighten headline leading before increasing font size if headings feel clumsy.
- Keep body text in a readable line-height range and avoid overly long line lengths.
- Reduce the number of active font sizes on a single screen.
- Use weight, size, spacing, and case deliberately instead of relying on one variable alone.

## Common failure modes

- Headings use body-copy line height and feel awkward.
- Every section introduces a slightly different size or weight.
- The design depends on all-caps or oversized labels to create hierarchy.
- Long paragraphs stretch too wide and become hard to track.

## When the heuristic bends

- Dense data tables or compact admin tools may need tighter body leading.
- Editorial layouts may use intentionally dramatic scale jumps.
- Expressive display typography can break conventional rhythm if the surrounding layout is restrained enough to support it.
