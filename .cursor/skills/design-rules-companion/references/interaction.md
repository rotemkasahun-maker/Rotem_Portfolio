# Interaction

Use this reference when controls feel small, crowded, ambiguous, or hard to operate.

## Core heuristics

- Interactive targets need enough size and separation to be reliably hit.
- Dense controls should still expose a clear primary action and clear secondary actions.
- The interface should reduce accidental taps and misclicks by spacing competing targets apart.
- State changes should be obvious through motion, contrast, or position rather than subtle decoration.

## Practical application

- Increase hit areas before increasing label verbosity.
- Separate destructive or high-risk actions from routine actions.
- Avoid stacking too many equally styled buttons in the same region.
- Make hover, focus, active, disabled, and selected states visibly different.

## Common failure modes

- Small icon buttons sit too close together.
- Every action is styled as primary.
- State changes depend on minor color shifts only.
- Dense rows of actions force the user to slow down and inspect every option.

## When the heuristic bends

- Power-user tools can support denser controls if shortcuts, patterns, and affordances are stable.
- Mobile and touch-heavy contexts usually need more generous spacing than desktop.
