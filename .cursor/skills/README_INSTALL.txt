ROTKA CURSOR SKILLS — INSTALLATION
==================================

This ZIP is ready to extract into the ROOT folder of a Cursor project.

1. Close Cursor or keep the project open.
2. Extract the ZIP into the project root (the folder containing package.json, .git, etc.).
3. Confirm this folder now exists:
   .cursor/skills/
4. Reopen the project or reload the Cursor window if the commands do not appear immediately.

Available skills / slash commands:

/portfolio-visual-director
/screenshot-to-implementation-spec
/family-finance-architecture-guardian
/feature-to-build-plan
/build-regression-qa

Each skill is project-local. Copy the same .cursor/skills folder into another repository if you want the five skills there too.
