# Rotem Portfolio v5

This build is a structural interaction pass, not a cosmetic revision.

## Added in v5
- Real mobile navigation drawer with focus trapping, Escape handling and animated open/close states.
- Case-study progress navigation.
- Optional reading mode for dense case-study passages using Lexend + bionic-style word emphasis.
- Interactive Family Finance ingestion preview rather than a static pipeline diagram.
- Real portfolio iteration history using preserved screenshots from earlier versions.
- Hero animation replay control.
- More intentional page transitions and active navigation feedback.
- Existing accessibility and reduced-motion support retained.

## Reading mode
The bionic-style treatment is optional rather than forced. It is applied only to selected dense paragraphs and uses Lexend for readability. The user can turn it on/off from the case-study progress bar.
