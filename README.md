# Rotem Kasahun Portfolio

Static React/Vite portfolio. No backend required.

## Run locally
npm install
npm run dev

## Build
npm run build

## Deploy to Vercel
- Import the GitHub repository
- Framework preset: Vite
- Build command: npm run build
- Output directory: dist

## Deploy to Netlify
- Build command: npm run build
- Publish directory: dist

## Notes
- Homepage fridge uses the current best Hidden/Visible assets and can be replaced later without changing structure.
- Family Finance Sections 1–2 preserve the approved narrative structure.
- About and Contact intentionally use TODO placeholders rather than invented copy or links.
